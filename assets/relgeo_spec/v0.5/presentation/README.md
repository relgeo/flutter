# Presentation

Status dokumen: `Informative Index`

Folder ini menampung lapisan presentasi gambar yang dibangun di atas model DSL.

Untuk kontrak aktif `v0.5`, area ini tetap normatif.

Namun secara konseptual, tidak semua topik di folder ini memiliki bobot yang sama:

1. sebagian dapat dibaca sebagai capability presentasi yang reusable
2. sebagian lain lebih berat ke domain `technical drawing`
3. keberadaan topik-topik ini di spec aktif tidak otomatis berarti semuanya adalah kapabilitas inti bahasa RelGeo

Urutan baca yang disarankan:

1. dimension objects
2. annotation objects
3. drawing roles
4. views dan sheets
5. metadata presentasional

Catatan:

1. `25-views-sheets.md` sengaja menggabungkan kontrak views dan sheets
2. jika nanti ukurannya membesar, file ini bisa dipecah tanpa mengubah struktur folder besar
3. pembacaan konseptual tentang batas `core / capability / domain` boleh dijelaskan di surface dokumentasi lain, tetapi tidak menjadi ketergantungan link dari source spec aktif
